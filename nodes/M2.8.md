# M2.8 Multiclass Softmax & Cross-Entropy

**Prerequisites / 前置**: [M2.7 Logistic Regression](M2.7.md)

## Content / 内容

For $K$ classes one keeps a weight vector $\mathbf{w}_k$ per class and defines the softmax probabilities
$$
P(y=k\mid\mathbf{x})=\frac{\exp(\mathbf{w}_k^\top\mathbf{x})}{\sum_{j=1}^K\exp(\mathbf{w}_j^\top\mathbf{x})}.
$$
The negative log-likelihood of a one-hot label $\mathbf{y}$ is
$$
J=-\sum_k y_k\log p_k.
$$
The gradient with respect to the score vector $\mathbf{z}=W\mathbf{x}$ is simply $\mathbf{p}-\mathbf{y}$; back-propagating through the linear map yields
$$
\nabla_{W}J = (\mathbf{p}-\mathbf{y})\mathbf{x}^\top.
$$
This is exactly the gradient used in the final layer of a neural network (node M8.3).

多分类用 softmax 把 $K$ 个线性分数变成概率分布，交叉熵梯度为 $\mathbf{p}-\mathbf{y}$。神经网络最后一层的梯度公式与此完全相同。

## Tiny Python sketch
```python
def softmax(Z):
    e = np.exp(Z - Z.max(axis=1, keepdims=True))
    return e / e.sum(axis=1, keepdims=True)
# gradient w.r.t. scores = probs - one_hot_labels
```

## Practice / 练习

Prove that the softmax probabilities sum to one and that the map $z_k\mapsto p_k$ is invariant to adding a constant to all scores.

<details>
<summary>Solution sketch</summary>

Numerator and denominator are multiplied by the same $e^{c}$, which cancels. Summation of the resulting fractions yields 1 by construction.

</details>
