## Content / 内容

The following identities are used constantly. Let $\mathbf{a}$ be a constant vector, $A$ a constant matrix, $\mathbf{x}$ the variable.

$$
\begin{align*}
\nabla_{\mathbf{x}}(\mathbf{a}^\top\mathbf{x}) &= \mathbf{a},\\
\nabla_{\mathbf{x}}(\mathbf{x}^\top A\mathbf{x}) &= (A+A^\top)\mathbf{x}
\quad\text{(if }A\text{ symmetric then }2A\mathbf{x}),\\
\nabla_{\mathbf{x}}\|A\mathbf{x}-\mathbf{b}\|_2^2 &= 2A^\top(A\mathbf{x}-\mathbf{b}).
\end{align*}
$$

Chain rule for a composition $f(g(\mathbf{x}))$ where $g:\mathbb{R}^d\to\mathbb{R}^m$ and $f:\mathbb{R}^m\to\mathbb{R}$:
$$
\nabla_{\mathbf{x}}f = (Dg)^\top\nabla_g f,
$$
where $Dg$ is the Jacobian matrix of $g$.

这些公式是所有闭式梯度和反向传播的“乘法表”。最小二乘的梯度、逻辑回归的梯度、SVM 对偶的梯度都是它们的直接实例。

**Why this matters later**  
You will never again expand a squared loss by hand; you simply write $\nabla=\!X^\top(X\mathbf{w}-\mathbf{y})$.

## Example / 例子

Least-squares objective $J(\mathbf{w})=\frac12\|X\mathbf{w}-\mathbf{y}\|_2^2$.  
By the third identity
$$
\nabla J = X^\top(X\mathbf{w}-\mathbf{y}).
$$
Setting the gradient to zero recovers the normal equations.

## Tiny Python sketch
```python
# verify the gradient of ½||Xw-y||² numerically
X = np.random.randn(5,3)
y = np.random.randn(5)
w = np.random.randn(3)
def J(w):
    return 0.5*np.sum((X@w-y)**2)
eps=1e-6
grad_num = np.array([(J(w+eps*e)-J(w))/eps for e in np.eye(3)])
grad_ana = X.T@(X@w-y)
print(np.allclose(grad_num, grad_ana))
```

## Practice / 练习

Derive $\nabla_{\mathbf{w}}\frac12\|\mathbf{w}\|_2^2$.

<details>
<summary>Solution sketch</summary>

$\frac12\mathbf{w}^\top\mathbf{w}$, apply the second identity with $A=I$ → $\nabla=\mathbf{w}$.

</details>
