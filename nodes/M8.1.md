## Content / 内容

A fully-connected layer computes $\mathbf{z}=W\mathbf{x}+\mathbf{b}$ followed by a point-wise non-linearity $\mathbf{h}=\phi(\mathbf{z})$. Stacking several such layers produces a **multilayer perceptron** (MLP). Common activations:
- sigmoid $\sigma(z)=1/(1+e^{-z})$ (historical);
- tanh (zero-centred);
- ReLU $\max(0,z)$ (modern default – cheap, avoids vanishing gradients for positive inputs).

The universal-approximation theorem guarantees that a single hidden layer with sufficiently many units can approximate any continuous function on a compact set arbitrarily well; depth often yields more parameter-efficient representations.

多层感知机 = 仿射变换 + 逐点非线性。ReLU 是目前最常用的激活。理论上单隐层已足够，实践中深度更高效。

## Tiny Python sketch
```python
import torch.nn as nn
model = nn.Sequential(
    nn.Linear(d, 128), nn.ReLU(),
    nn.Linear(128, 64), nn.ReLU(),
    nn.Linear(64, K)
)
```

## Practice / 练习

Why is a composition of purely linear layers still only a linear map? What does the non-linearity buy us?

<details>
<summary>Solution sketch</summary>

Matrix multiplication is associative: $W_2(W_1\mathbf{x})=(W_2W_1)\mathbf{x}$. Non-linearities break this collapse and allow the network to form complex decision regions.

</details>
