## Content / 内容

An $m\times n$ matrix $A$ defines a linear map $\mathbb{R}^n\to\mathbb{R}^m$ by $\mathbf{y}=A\mathbf{x}$.  
The product $A\mathbf{x}$ is the linear combination of the **columns** of $A$ with coefficients given by the entries of $\mathbf{x}$.  
Matrix–matrix multiplication $(AB)_{ik}=\sum_j A_{ij}B_{jk}$ is associative but not commutative.  
The transpose satisfies $(AB)^\top=B^\top A^\top$ and $(\mathbf{x}^\top A\mathbf{y})=\langle\mathbf{x},A\mathbf{y}\rangle$.  
A matrix is symmetric when $A=A^\top$.  
A data matrix $X\in\mathbb{R}^{n\times d}$ can be viewed either as $n$ row vectors (samples) or as $d$ column vectors (features).

矩阵乘法把向量写成列的线性组合。转置反转乘积顺序。数据矩阵既可看成样本行，也可看成特征列。

**Why this matters later**  
- The design matrix of linear regression is exactly this $X$.  
- The covariance matrix is $X^\top X$ (or a scaled version).  
- Every neural-network layer is a matrix multiplication followed by a non-linearity.

## Example / 例子

$$
A=\begin{pmatrix}1&2\\3&4\end{pmatrix},\quad
\mathbf{x}=\begin{pmatrix}1\\1\end{pmatrix}
\quad\Rightarrow\quad
A\mathbf{x}=\begin{pmatrix}3\\7\end{pmatrix}
= 1\cdot\begin{pmatrix}1\\3\end{pmatrix}+1\cdot\begin{pmatrix}2\\4\end{pmatrix}.
$$

## Tiny Python sketch
```python
A = np.array([[1.,2.],[3.,4.]])
x = np.array([1.,1.])
print(A @ x)          # [3. 7.]
print(A.T @ A)        # Gram matrix
```

## Practice / 练习

Show that if $A$ is $m\times n$ and $\mathbf{x}\in\mathbb{R}^n$, then $\|A\mathbf{x}\|_2\le\|A\|_F\|\mathbf{x}\|_2$ where $\|A\|_F$ is the Frobenius norm $\sqrt{\sum_{ij}A_{ij}^2}$.

<details>
<summary>Solution sketch</summary>

$\|A\mathbf{x}\|_2^2=\sum_i(\sum_j A_{ij}x_j)^2\le\sum_i(\sum_j A_{ij}^2)(\sum_j x_j^2)$ by Cauchy–Schwarz on each row, which sums to $\|A\|_F^2\|\mathbf{x}\|_2^2$.

</details>
