# M7.1 Entropy & Information Gain

**Prerequisites / 前置**: none

---

## Content / 内容

For a discrete label distribution $\mathbf{p}=(p_1,\dots,p_K)$ the **Shannon entropy** is
$$
H(\mathbf{p})=-\sum_k p_k\log_2 p_k
$$
(with the convention $0\log0=0$). Entropy is zero for a pure distribution and maximal for the uniform distribution.  
**Information gain** of a split that partitions the data into subsets $S_j$ is
$$
\mathrm{IG}=H(S)-\sum_j\frac{|S_j|}{|S|}H(S_j).
$$
Decision-tree algorithms greedily choose the split that maximises IG.

熵衡量标签的不确定性。信息增益 = 分裂前熵 − 分裂后加权平均熵。决策树每一步选择增益最大的分裂。

## Tiny Python sketch
```python
def entropy(y):
    _, counts = np.unique(y, return_counts=True)
    p = counts / counts.sum()
    return -np.sum(p * np.log2(p + 1e-12))
```

## Practice / 练习

Compute the entropy of a binary set with 3 positive and 1 negative examples, and the information gain of a split that separates them into (2 pos) and (1 pos + 1 neg).

<details>
<summary>Solution sketch</summary>

$H= -\frac34\log_2\frac34-\frac14\log_2\frac14\approx0.811$.  
After split: $H_1=0$, $H_2=1$, weighted average $0.5$. IG $\approx0.811-0.5=0.311$.

</details>
