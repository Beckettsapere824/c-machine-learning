# M4.2 PCA – Principal Axes via Eigendecomposition

**Prerequisites / 前置**: [M4.1 Covariance](M4.1.md), [M0.5 Eigenvalues](M0.5.md)

## Content / 内容

Principal Component Analysis looks for the direction of maximum variance:
$$
\max_{\|\mathbf{u}\|_2=1}\mathbf{u}^\top\Sigma\mathbf{u}.
$$
By the Rayleigh-quotient characterisation (M0.5) the maximiser is the leading eigenvector of $\Sigma$ and the maximal value is the leading eigenvalue $\lambda_1$. The second principal axis solves the same problem in the orthogonal complement of the first, and so on. Consequently the complete set of principal axes is given by the spectral decomposition
$$
\Sigma = Q\Lambda Q^\top,
$$
ordered $\lambda_1\ge\lambda_2\ge\dots\ge\lambda_d$.  
The reconstruction error incurred by keeping only the first $k$ components equals the sum of the discarded eigenvalues:
$$
\frac1n\|\tilde{X}-\tilde{X}Q_{:,1:k}Q_{:,1:k}^\top\|_F^2 = \sum_{j=k+1}^d\lambda_j.
$$

PCA = 协方差矩阵的谱分解。最大方差方向 = 最大特征值对应的特征向量。截断后的重构误差 = 被丢弃的特征值之和。

## Tiny Python sketch
```python
lam, Q = np.linalg.eigh(Sigma)   # ascending order
idx = np.argsort(lam)[::-1]
lam, Q = lam[idx], Q[:,idx]
X_pca = X_c @ Q[:,:k]
```

## Practice / 练习

Why is the total variance of the data equal to $\mathrm{tr}(\Sigma)=\sum_i\lambda_i$?

<details>
<summary>Solution sketch</summary>

$\mathrm{tr}(\Sigma)=\mathrm{tr}(Q\Lambda Q^\top)=\mathrm{tr}(\Lambda)$ by the cyclic property of the trace.

</details>
