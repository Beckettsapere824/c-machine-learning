# M2.6 Adaline & Continuous Activation

## Content / 内容

Adaline (Adaptive Linear Neuron) replaces the hard threshold by the identity activation and minimises the squared loss between the continuous output and the target:
$$
J(\mathbf{w})=\frac12\sum_i(\mathbf{w}^\top\mathbf{x}_i-y_i)^2.
$$
The gradient is identical to ordinary least squares, so the same closed-form solution or gradient-descent updates apply. The final classification is obtained by thresholding the continuous prediction.  
Because the loss is differentiable everywhere, Adaline can be trained by full-batch gradient descent or SGD; the Perceptron, by contrast, only updates on errors and never uses a continuous loss.

Adaline 用恒等激活 + 平方损失，梯度与最小二乘相同。最终分类仍通过阈值得到。与感知机的关键区别是损失可处处求导。

## Comparison table

| | Perceptron | Adaline |
|---|---|---|
| activation | sign | identity |
| loss | 0-1 (implicit) | squared |
| update | only on errors | every sample |
| convergence | finite on separable data | linear rate on quadratic |

## Tiny Python sketch
```python
# Adaline is just least-squares followed by a threshold
w = np.linalg.lstsq(X, y, rcond=None)[0]
y_hat = np.sign(X @ w)
```

## Practice / 练习

Why can Adaline still converge on data that are not linearly separable while the classic Perceptron cannot?

<details>
<summary>Solution sketch</summary>

Adaline minimises a convex quadratic that always possesses a global minimum; the Perceptron seeks a separating hyperplane that may not exist and therefore may loop forever.

</details>
