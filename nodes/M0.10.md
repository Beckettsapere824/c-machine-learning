# M0.10 Unconstrained Optimality Condition ($\nabla f=0$)

**Prerequisites / 前置**: [M0.8 Matrix Calculus](M0.8.md), [M0.9 Convexity](M0.9.md)

---

## Content / 内容

If $\mathbf{x}^*$ is a local minimiser of a differentiable function $f$ and $\mathbf{x}^*$ lies in the interior of the domain, then necessarily
$$
\nabla f(\mathbf{x}^*)=\mathbf{0}.
$$
When $f$ is convex the condition is also sufficient: every stationary point is a global minimiser.  
If $f$ is twice continuously differentiable and $\nabla^2 f(\mathbf{x}^*)\succ0$ (positive definite Hessian), then $\mathbf{x}^*$ is a strict local minimiser.

可微函数的局部极小点处梯度必须为零。若函数还是凸的，则该条件充分，且极小是全局的。

**Why this matters later**  
Setting the gradient of the least-squares objective to zero yields the normal equations. Setting the gradient of the logistic-regression negative log-likelihood to zero yields the critical-point equation that gradient descent solves.

## Example / 例子

$J(w)=\frac12(w-3)^2$. $\nabla J=w-3=0\Rightarrow w^*=3$, which is indeed the unique global minimiser.

## Practice / 练习

Show that for a convex differentiable $f$, if $\nabla f(\mathbf{x}^*)=0$ then $\mathbf{x}^*$ is a global minimiser.

<details>
<summary>Solution sketch</summary>

By the first-order characterisation $f(\mathbf{y})\ge f(\mathbf{x}^*)+\langle\nabla f(\mathbf{x}^*),\mathbf{y}-\mathbf{x}^*\rangle=f(\mathbf{x}^*)$ for every $\mathbf{y}$.

</details>
