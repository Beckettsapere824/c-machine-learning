## Content / 内容

Agglomerative clustering starts with each point as its own cluster and repeatedly merges the two closest clusters until only one remains. The resulting binary tree is the **dendrogram**.  
The distance between two clusters is defined by a **linkage**:
- single: minimum pairwise distance;
- complete: maximum pairwise distance;
- average: mean pairwise distance;
- Ward: increase in total within-cluster variance caused by the merge.

Different linkages produce qualitatively different dendrograms; Ward’s linkage tends to yield compact, equal-sized clusters and is often preferred.

自底向上合并，用 linkage 定义簇间距离。树状图（dendrogram）记录整个合并历史。Ward linkage 使合并后的方差增加最小。

## Tiny Python sketch
```python
from scipy.cluster.hierarchy import linkage, dendrogram
Z = linkage(X, method='ward')
dendrogram(Z)
```

## Practice / 练习

In single linkage, a single noisy bridge between two dense groups can cause them to merge early. Which linkage is most robust to this phenomenon?

<details>
<summary>Solution sketch</summary>

Complete linkage (or Ward) requires all pairs (or the variance criterion) to be close, so a single bridge is ignored.

</details>
