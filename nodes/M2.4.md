## Content / 内容

When $n$ or $d$ is huge the normal equations become expensive ($O(nd^2+d^3)$). Gradient descent replaces the closed form by the iteration
$$
\mathbf{w}\leftarrow\mathbf{w}-\eta\nabla J(\mathbf{w})
=\mathbf{w}-\eta X^\top(X\mathbf{w}-\mathbf{y}).
$$
Three practical variants:
- **Batch**: use the full sum every step (stable, expensive);
- **Stochastic (SGD)**: use a single randomly chosen residual (noisy, cheap);
- **Mini-batch**: compromise—average a small random subset.

For a quadratic with positive-definite Hessian the batch method converges linearly when $0<\eta<2/\lambda_{\max}(X^\top X)$. Adaptive step-size rules (line search, Adam, …) are used in practice.

梯度下降用迭代代替闭式解。批量、随机、小批量三种模式在稳定性与计算量之间权衡。

## Why the learning-rate bound exists / 步长上界的来源

The gradient of a quadratic $J(\mathbf{w})=\frac12\mathbf{w}^\top A\mathbf{w}-\mathbf{b}^\top\mathbf{w}$ is $A\mathbf{w}-\mathbf{b}$. The iteration is a linear map whose spectral radius is less than 1 precisely when $\eta\in(0,2/\lambda_{\max}(A))$.

## Tiny Python sketch
```python
def gd(X, y, eta=0.01, n_iter=1000):
    w = np.zeros(X.shape[1])
    for _ in range(n_iter):
        w -= eta * X.T @ (X@w - y)
    return w
```

## Practice / 练习

Show that one step of gradient descent on $J(w)=\frac12(w-3)^2$ with step-size $\eta$ yields $w\leftarrow(1-\eta)w+3\eta$. For which $\eta$ does the fixed point $w=3$ become attractive?

<details>
<summary>Solution sketch</summary>

$|1-\eta|<1\Leftrightarrow\eta\in(0,2)$. The same interval appears for any one-dimensional quadratic.

</details>
