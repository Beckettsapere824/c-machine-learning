## Content / 内容

Every neural-network computation can be represented as a directed acyclic **computational graph**. Nodes are elementary operations (add, multiply, ReLU, …); edges carry values. The **forward pass** evaluates the graph in topological order, producing the final loss (or prediction).  
Keeping the intermediate values is essential for the subsequent backward pass.

计算图把网络表达为 DAG。前向传播按拓扑序计算并缓存中间结果，供反向传播使用。

## Tiny Python sketch
```python
# PyTorch builds the graph dynamically
x = torch.randn(4, d, requires_grad=True)
loss = model(x).sum()
# intermediate tensors are retained automatically
```
