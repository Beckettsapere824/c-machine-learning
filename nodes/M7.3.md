## Content / 内容

A decision tree is grown by recursive binary (CART) or multi-way (ID3) partitioning:
1. At each node compute the impurity (Gini or entropy).
2. Evaluate every possible split (for continuous features, every midpoint between sorted values).
3. Choose the split with maximal impurity decrease / information gain.
4. Stop when a node is pure, contains fewer than $n_{\min}$ samples, or has reached maximum depth.

The resulting axis-aligned partitions are easy to interpret but prone to overfitting if grown to purity.

递归选择使不纯度下降最大的分裂。连续特征需排序后考察所有中点。树可解释但易过拟合。

## Tiny Python sketch
```python
from sklearn.tree import DecisionTreeClassifier
tree = DecisionTreeClassifier(criterion='gini', max_depth=3)
```

## Practice / 练习

Why does the number of candidate thresholds for a continuous feature equal $n-1$ (after sorting)?

<details>
<summary>Solution sketch</summary>

Only the midpoints between consecutive distinct values can change the assignment of samples; there are at most $n-1$ such midpoints.

</details>
