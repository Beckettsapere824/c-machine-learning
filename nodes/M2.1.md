# M2.1 Linear Regression – Model & Squared Loss

**Prerequisites / 前置**: [M0.8 Matrix Calculus](M0.8.md)

---

## Content / 内容

We observe pairs $(\mathbf{x}_i,y_i)\in\mathbb{R}^d\times\mathbb{R}$. The linear model predicts
$$
\hat{y}_i = f(\mathbf{x}_i;\mathbf{w}) = \mathbf{w}^\top\mathbf{x}_i
$$
(or $w_0+\mathbf{w}^\top\mathbf{x}_i$ after appending a constant-1 feature). The residual is $r_i=\hat{y}_i-y_i$.  
Empirical risk under the squared loss is
$$
J(\mathbf{w}) = \frac12\sum_{i=1}^n r_i^2 = \frac12\|X\mathbf{w}-\mathbf{y}\|_2^2,
$$
where $X\in\mathbb{R}^{n\times d}$ stacks the training vectors as rows.  
The factor $\frac12$ is pure convenience: it cancels the 2 that appears when differentiating.

线性模型 $\hat{y}=\mathbf{w}^\top\mathbf{x}$，平方损失的经验风险写成矩阵形式 $\frac12\|X\mathbf{w}-\mathbf{y}\|_2^2$。后续所有闭式解和梯度都从这一行出发。

**Link back to M0**  
The gradient identity $\nabla\|A\mathbf{w}-\mathbf{b}\|_2^2=2A^\top(A\mathbf{w}-\mathbf{b})$ (node M0.8) is applied verbatim here with $A=X$.

## Geometric view / 几何视角

$X\mathbf{w}$ is the linear combination of the columns of $X$ that lies closest (in Euclidean distance) to the vector $\mathbf{y}$. Least squares is orthogonal projection onto the column space of $X$.

## Tiny Python sketch
```python
X = np.random.randn(20, 3)
y = X @ np.array([1., -2., 0.5]) + 0.1*np.random.randn(20)
# J(w) = 0.5 * ||Xw - y||^2
```

## Practice / 练习

Write $J(w_0,w_1)$ explicitly for the one-dimensional model $f(x)=w_0+w_1x$ and three points $(1,2)$, $(2,3)$, $(3,5)$.

<details>
<summary>Solution sketch</summary>

$J=\frac12\bigl[(w_0+w_1-2)^2+(w_0+2w_1-3)^2+(w_0+3w_1-5)^2\bigr]$.

</details>
