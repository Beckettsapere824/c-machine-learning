# M6.3 Boosting Idea & AdaBoost Derivation

## Content / 内容

Boosting builds an additive ensemble $F(\mathbf{x})=\sum_t\alpha_t h_t(\mathbf{x})$ by successively fitting weak learners to re-weighted data that emphasise previously misclassified points.  
AdaBoost minimises the exponential loss $\sum_i\exp(-y_i F(\mathbf{x}_i))$ by the following stage-wise procedure:
1. Fit $h_t$ to the current weighted distribution $D_t$;
2. Compute weighted error $\varepsilon_t$ and set $\alpha_t=\frac12\ln\frac{1-\varepsilon_t}{\varepsilon_t}$;
3. Update $D_{t+1}(i)\propto D_t(i)\exp(-\alpha_t y_i h_t(\mathbf{x}_i))$.

The final classifier is $\mathrm{sign}(F(\mathbf{x}))$. The exponential loss is an upper bound on the 0-1 loss and is convex, which explains the algorithm’s strong empirical performance.

Boosting 串行地拟合弱学习器，每次提高错分样本的权重。AdaBoost 的 $\alpha_t$ 与权重更新来自指数损失的阶段最小化。

from sklearn.ensemble import AdaBoostClassifier

## Practice / 练习

Derive the optimal $\alpha$ for a fixed weak learner $h$ under exponential loss (assume binary labels $\pm1$).

<details>
<summary>Solution sketch</summary>

$L(\alpha)=\sum_i D_i\exp(-\alpha y_i h(\mathbf{x}_i))=e^{-\alpha}(1-\varepsilon)+e^{\alpha}\varepsilon$.  
Set derivative to zero: $-e^{-\alpha}(1-\varepsilon)+e^{\alpha}\varepsilon=0\Rightarrow\alpha=\frac12\ln\frac{1-\varepsilon}{\varepsilon}$.

</details>
