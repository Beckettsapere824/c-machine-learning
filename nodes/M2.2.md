# M2.2 Normal Equations & Closed-Form Solution

**Prerequisites / 前置**: [M2.1 Linear Regression](M2.1.md), [M0.4 Rank](M0.4.md), [M0.10 Optimality](M0.10.md)

---

## Content / 内容

Because $J(\mathbf{w})=\frac12\|X\mathbf{w}-\mathbf{y}\|_2^2$ is a convex quadratic (Hessian $X^\top X\succeq0$), any stationary point is a global minimiser. Setting the gradient to zero yields the **normal equations**
$$
X^\top X\,\mathbf{w} = X^\top\mathbf{y}.
$$
When $X$ has full column rank, $X^\top X$ is invertible and the unique solution is
$$
\hat{\mathbf{w}} = (X^\top X)^{-1}X^\top\mathbf{y}.
$$
If rank is deficient one uses the Moore-Penrose pseudo-inverse; the solution then has minimum Euclidean norm among all minimisers.

令梯度为零得到正规方程 $X^\top X\mathbf{w}=X^\top\mathbf{y}$。满列秩时闭式解唯一；否则需伪逆。

**Derivation in one line**  
$\nabla J = X^\top(X\mathbf{w}-\mathbf{y})=0$ (M0.8) $\Rightarrow$ normal equations.

## Geometric meaning / 几何意义

The residual $\mathbf{y}-X\hat{\mathbf{w}}$ is orthogonal to every column of $X$ (i.e. to the whole column space). That is exactly the defining property of orthogonal projection.

## Tiny Python sketch
```python
w_hat = np.linalg.lstsq(X, y, rcond=None)[0]
# or explicitly:
w_hat = np.linalg.solve(X.T@X, X.T@y)   # when full rank
```

## Practice / 练习

For the three points of M2.1, form the design matrix with intercept, write the $2\times2$ normal equations and solve for $(w_0,w_1)$.

<details>
<summary>Solution sketch</summary>

$X=\begin{pmatrix}1&1\\1&2\\1&3\end{pmatrix}$, $X^\top X=\begin{pmatrix}3&6\\6&14\end{pmatrix}$, $X^\top y=\begin{pmatrix}10\\23\end{pmatrix}$.  
Solution $w_0=\frac23$, $w_1=\frac32$.
