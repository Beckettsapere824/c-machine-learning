# M0.4 Rank, Column Space, Null Space, Invertibility

**Prerequisites / 前置**: [M0.3 Matrices](M0.3.md)

---

## Content / 内容

The **column space** $\mathrm{Col}(A)$ is the span of the columns of $A$.  
The **null space** $\mathrm{Null}(A)=\{\mathbf{x}\mid A\mathbf{x}=\mathbf{0}\}$.  
Rank-nullity theorem:
$$
\mathrm{rank}(A)+\dim\mathrm{Null}(A)=n
$$
(for an $m\times n$ matrix).  
$A$ has full column rank when $\mathrm{rank}(A)=n$ (i.e. columns are linearly independent). In that case the Gram matrix $A^\top A$ is invertible and the normal equations of least squares possess a unique solution.

列空间是列的张成，零空间是被映到零的向量。秩-零度定理决定了 $A^\top A$ 是否可逆——这直接决定最小二乘是否有唯一闭式解。

**Why this matters later**  
If the design matrix $X$ does not have full column rank (duplicate features, too many polynomial terms, …) then $X^\top X$ is singular and the normal equations fail. Regularisation or pseudo-inverse become necessary.

## Example / 例子

$$
A=\begin{pmatrix}1&2\\2&4\\3&6\end{pmatrix}
$$
has rank 1, null-space dimension 1 (the vector $(2,-1)^\top$).  
$A^\top A$ is singular.

## Tiny Python sketch
```python
A = np.array([[1.,2.],[2.,4.],[3.,6.]])
print(np.linalg.matrix_rank(A))          # 1
print(np.linalg.det(A.T @ A))            # 0.0 (singular)
```

## Practice / 练习

Prove that $\mathrm{Null}(A^\top A)=\mathrm{Null}(A)$.

<details>
<summary>Solution sketch</summary>

$A^\top A\mathbf{x}=0\Rightarrow\mathbf{x}^\top A^\top A\mathbf{x}=0\Rightarrow\|A\mathbf{x}\|_2^2=0\Rightarrow A\mathbf{x}=0$. The other inclusion is obvious.

</details>
