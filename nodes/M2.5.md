# M2.5 Perceptron Learning Rule

## Content / 内容

The classical Perceptron is a linear threshold classifier
$$
\hat{y} = \mathrm{sign}(\mathbf{w}^\top\mathbf{x}),\qquad
\mathrm{sign}(z)=\begin{cases}+1&z\ge0\\-1&z<0.\end{cases}
$$
When a training point $(\mathbf{x}_i,y_i)$ is misclassified ($y_i(\mathbf{w}^\top\mathbf{x}_i)\le0$) the weight is updated by
$$
\mathbf{w}\leftarrow\mathbf{w}+y_i\mathbf{x}_i.
$$
If the data are linearly separable the algorithm terminates after a finite number of updates (Novikoff’s bound). On non-separable data it cycles indefinitely; practical implementations therefore impose a maximum epoch count.

感知机用符号函数做线性分类。错分时执行 $\mathbf{w}\leftarrow\mathbf{w}+y_i\mathbf{x}_i$。线性可分时有限步收敛。

**Geometric reading**  
The update adds a positive multiple of the misclassified point (or its negative) to the weight vector, rotating the decision hyperplane so that the point moves toward the correct half-space.

## Tiny Python sketch
```python
def perceptron(X, y, n_epoch=10):
    w = np.zeros(X.shape[1])
    for _ in range(n_epoch):
        for x, label in zip(X, y):
            if label * (w @ x) <= 0:
                w += label * x
    return w
```
