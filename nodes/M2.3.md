# M2.3 Polynomial Features & Overfitting

**Prerequisites / 前置**: [M2.2 Normal Equations](M2.2.md)

---

## Content / 内容

A linear model in the original coordinates can still represent non-linear functions by expanding the feature map
$$
\phi(x)=(1,x,x^2,\dots,x^p)^\top.
$$
The design matrix then becomes the Vandermonde matrix whose columns are successive powers. The same normal equations apply in the expanded space.

As $p$ grows the model can interpolate any $n$ points (when $p\ge n-1$), driving training loss to zero while the prediction oscillates wildly between data points—classic **overfitting**. The bias-variance decomposition makes the trade-off quantitative: higher $p$ decreases bias but increases variance.

通过多项式特征映射，线性模型可以拟合曲线。阶数过高会在训练点之间剧烈振荡（过拟合）。

## Concrete picture / 具体图像

Ten points drawn from $y=\sin(2\pi x)+$noise.  
- degree 1: underfit, high bias;  
- degree 3: reasonable fit;  
- degree 9: trains to zero error, test error explodes.

## Tiny Python sketch
```python
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
poly = PolynomialFeatures(degree=3)
X_poly = poly.fit_transform(X)
model = LinearRegression().fit(X_poly, y)
```

## Practice / 练习

Why does the condition number of $X^\top X$ typically explode when high-degree monomials are included?

<details>
<summary>Solution sketch</summary>

Columns $x^j$ and $x^{j+1}$ become almost linearly dependent on a bounded interval, making $X^\top X$ nearly singular (large condition number) and the numerical solution unstable.

</details>
