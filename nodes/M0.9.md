# M0.9 Convex Sets, Convex Functions, First-order Characterisation

**Prerequisites / 前置**: [M0.7 Gradient](M0.7.md)

---

## Content / 内容

A set $C\subseteq\mathbb{R}^d$ is **convex** if for any $\mathbf{x},\mathbf{y}\in C$ and $\theta\in[0,1]$
$$
\theta\mathbf{x}+(1-\theta)\mathbf{y}\in C.
$$
A function $f$ is **convex** if its domain is convex and
$$
f(\theta\mathbf{x}+(1-\theta)\mathbf{y})\le\theta f(\mathbf{x})+(1-\theta)f(\mathbf{y}).
$$
When $f$ is differentiable an equivalent first-order characterisation is
$$
f(\mathbf{y})\ge f(\mathbf{x})+\nabla f(\mathbf{x})^\top(\mathbf{y}-\mathbf{x})\qquad\forall\mathbf{y}.
$$
Geometrically the graph of $f$ lies above all of its tangent planes.  
A twice-differentiable function is convex if and only if its Hessian is positive semi-definite everywhere.

凸函数的图像总在切平面上方。一阶条件是后续证明“局部最小即全局最小”的关键工具。

**Why this matters later**  
Least-squares, logistic regression (with the right loss), and the dual of SVM are all convex problems. Convexity guarantees that any point where the gradient vanishes is a global minimiser; there are no “bad” local minima to worry about.

## Example / 例子

$f(x)=x^2$ is convex; $f(x)=-x^2$ is concave; $f(x)=|x|$ is convex but not differentiable at 0.

## Practice / 练习

Use the first-order characterisation to prove that $f(\mathbf{x})=\|\mathbf{x}\|_2^2$ is convex.

<details>
<summary>Solution sketch</summary>

$\nabla f=2\mathbf{x}$, so $f(\mathbf{y})-f(\mathbf{x})-\nabla f(\mathbf{x})^\top(\mathbf{y}-\mathbf{x})=\|\mathbf{y}\|^2-\|\mathbf{x}\|^2-2\mathbf{x}^\top(\mathbf{y}-\mathbf{x})=\|\mathbf{y}-\mathbf{x}\|^2\ge0$.

</details>
