# M2.7 Logistic Regression – Model & Cross-Entropy Loss

**Prerequisites / 前置**: [M2.6 Adaline](M2.6.md), [M0.8 Matrix Calculus](M0.8.md)

---

## Content / 内容

Logistic regression models the probability of the positive class by the sigmoid of a linear score:
$$
P(y=1\mid\mathbf{x})=\sigma(\mathbf{w}^\top\mathbf{x}),\qquad
\sigma(z)=\frac{1}{1+e^{-z}}.
$$
The negative log-likelihood (cross-entropy) on a data set is
$$
J(\mathbf{w})=-\sum_i\bigl[y_i\log\sigma_i+(1-y_i)\log(1-\sigma_i)\bigr],
$$
where $\sigma_i=\sigma(\mathbf{w}^\top\mathbf{x}_i)$. Differentiating yields the elegant gradient
$$
\nabla J = \sum_i(\sigma_i-y_i)\mathbf{x}_i = X^\top(\boldsymbol{\sigma}-\mathbf{y}).
$$
Because $J$ is convex, any local minimum is global; gradient descent (or Newton / L-BFGS) reliably finds the maximum-likelihood estimator.

逻辑回归用 sigmoid 把线性分数变成概率，最大化似然等价于最小化交叉熵。梯度为 $X^\top(\sigma-y)$，形式与最小二乘几乎相同。

**Link to M0.8**  
The chain rule applied to $\log\sigma(z)$ and $\log(1-\sigma(z))$ produces the factor $(\sigma-y)$; the rest is ordinary matrix calculus.

## Tiny Python sketch
```python
def sigmoid(z):
    return 1/(1+np.exp(-z))
def grad(w, X, y):
    return X.T @ (sigmoid(X@w) - y)
```

## Practice / 练习

Show that $\sigma'(z)=\sigma(z)(1-\sigma(z))$. Why does this identity simplify the gradient derivation?

<details>
<summary>Solution sketch</summary>

Direct differentiation of $1/(1+e^{-z})$. In the chain rule the derivative of the log-loss contributes a factor $1/\sigma$ or $1/(1-\sigma)$ that cancels with $\sigma'$, leaving the clean residual $\sigma-y$.

</details>
