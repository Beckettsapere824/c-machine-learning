# M0.7 Partial Derivatives and Gradient of a Scalar Function

**Prerequisites / 前置**: [M0.1 Vectors](M0.1.md)

---

## Content / 内容

For a scalar function $f:\mathbb{R}^d\to\mathbb{R}$ the **partial derivative** with respect to the $i$-th coordinate is
$$
\frac{\partial f}{\partial x_i}(\mathbf{x})
=\lim_{h\to0}\frac{f(\mathbf{x}+h\mathbf{e}_i)-f(\mathbf{x})}{h}.
$$
The **gradient** is the column vector of all partials
$$
\nabla f(\mathbf{x})=\begin{pmatrix}\partial f/\partial x_1\\\vdots\\\partial f/\partial x_d\end{pmatrix}.
$$
The directional derivative in direction $\mathbf{u}$ ($\|\mathbf{u}\|_2=1$) equals $\langle\nabla f(\mathbf{x}),\mathbf{u}\rangle$. Consequently $\nabla f$ points in the direction of steepest ascent and $-\nabla f$ is the direction of steepest descent.

梯度是偏导数组成的向量，指向函数上升最快的方向。所有基于梯度的优化算法（梯度下降、反向传播）都建立在这个几何事实上。

**Why this matters later**  
Every derivation of a gradient-descent update (least squares, logistic regression, neural nets) begins by writing $\nabla_w J$.

## Example / 例子

$f(x,y)=x^2+3xy+y^2$.  
$\partial f/\partial x=2x+3y$, $\partial f/\partial y=3x+2y$, so
$$
\nabla f=\begin{pmatrix}2x+3y\\3x+2y\end{pmatrix}.
$$

## Tiny Python sketch
```python
# finite-difference check
def f(x):
    return x[0]**2 + 3*x[0]*x[1] + x[1]**2
x = np.array([1., 2.])
eps = 1e-5
grad_approx = np.array([
    (f(x+eps*np.array([1.,0]))-f(x))/eps,
    (f(x+eps*np.array([0.,1]))-f(x))/eps
])
print(grad_approx)   # ≈ [8. 7.]
```

## Practice / 练习

Compute $\nabla\|\mathbf{x}\|_2^2$.

<details>
<summary>Solution sketch</summary>

$\|\mathbf{x}\|_2^2=\sum x_i^2$, partial w.r.t. $x_i$ is $2x_i$, therefore $\nabla=2\mathbf{x}$.

</details>
