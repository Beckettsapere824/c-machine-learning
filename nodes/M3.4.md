# M3.4 Kernel Trick & Positive-Definite Kernels

**Prerequisites / 前置**: [M3.2 Hard-Margin Dual](M3.2.md), [M0.6 Positive-Definite Matrices](M0.6.md)

---

## Content / 内容

In the dual the data appear only through inner products $\langle\mathbf{x}_i,\mathbf{x}_j\rangle$. Replace the input space by a feature map $\phi:\mathbb{R}^d\to\mathcal{H}$ and the dual becomes
$$
g(\boldsymbol{\alpha})=\sum_i\alpha_i-\tfrac12\sum_{i,j}\alpha_i\alpha_j y_i y_j\langle\phi(\mathbf{x}_i),\phi(\mathbf{x}_j)\rangle.
$$
If we can compute the kernel function
$$
k(\mathbf{x},\mathbf{z})=\langle\phi(\mathbf{x}),\phi(\mathbf{z})\rangle
$$
directly, we never need to form $\phi(\mathbf{x})$ explicitly—the **kernel trick**.  
A symmetric function $k$ is a valid kernel if and only if the Gram matrix $K_{ij}=k(\mathbf{x}_i,\mathbf{x}_j)$ is positive semi-definite for every finite set of points (Mercer’s condition).

Common kernels:
- linear: $k(\mathbf{x},\mathbf{z})=\langle\mathbf{x},\mathbf{z}\rangle$
- polynomial: $k(\mathbf{x},\mathbf{z})=(\langle\mathbf{x},\mathbf{z}\rangle+c)^p$
- Gaussian RBF: $k(\mathbf{x},\mathbf{z})=\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|_2^2)$

对偶里数据只以正积形式出现。核函数 $k(\mathbf{x},\mathbf{z})=\langle\phi(\mathbf{x}),\phi(\mathbf{z})\rangle$ 让我们在不显式计算 $\phi$ 的情况下使用高维（甚至无限维）特征空间。

## Tiny Python sketch
```python
from sklearn.svm import SVC
clf = SVC(kernel='rbf', gamma=0.5, C=1.0)
clf.fit(X, y)
```

## Practice / 练习

Show that the polynomial kernel $(\langle\mathbf{x},\mathbf{z}\rangle+1)^2$ corresponds to the explicit feature map that contains all monomials of degree ≤2.

<details>
<summary>Solution sketch</summary>

Expand: $\sum_i x_i^2z_i^2 + \sum_{i\ne j}x_ix_jz_iz_j + 2\sum_i x_iz_i +1$.  
These are exactly the inner products of the vectors $(x_1^2,\dots,x_d^2,\sqrt{2}x_1x_2,\dots,\sqrt{2}x_i,\dots,1)$.

</details>
