# .grok / agent harness

This directory (and the root `AGENT.md` / `MEMORY.md`) are the **persistent harness** so any agent can continue work without the original chat.

| File | Purpose |
|------|---------|
| `../AGENT.md` | Operating contract, workflow, non-negotiables |
| `../MEMORY.md` | Status, formula bugs, decisions, log |
| `../CONSTRUCTION.md` | Node writing standard |
| `../data/prerequisite_tree.yaml` | Index + 思路 for every node |

Optional future: put model-specific notes here (`claude.md` aliases can simply point to `AGENT.md`).
