## 4.1 Random Variables

**Definition 4.1**  
A random variable \(X : \Omega \to \mathbb{R}\) is a numerical-valued function on a sample space.  
\(X=x\) stands for the event \(\{\omega\in\Omega : X(\omega)=x\}\).

Example (3 cards, number of aces): support \(\{0,1,2,3\}\), explicit probabilities via hypergeometric-style counting.

Convention: capital letters = random variables; small letters = realized values.

## 4.2 Distribution of the Discrete Type

**Definition 4.2**  
\(X\) is discrete if \(X(\Omega)\) is countable.

### 4.2.1 Probability Mass Function and Distribution Function

**Definition 4.3**  
pmf: \(p(x) = \Pr(X=x)\) for \(x\in X(\Omega)\).
