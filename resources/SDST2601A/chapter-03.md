## 3.1 The Mathematical Theory of Probability

Kolmogorov’s axiomatic structure (1933). Uncertain situations are modelled via a set of possible outcomes (sample space).

### 3.1.1 Language of Sets
- **Set**: precisely specified collection of objects.
- **Element**: object in the set.
- Examples: faces of a die, outcomes of two coin flips, students in the course.

### Venn diagrams
Visual representation of relationships between sets.

### 3.1.1.2 Set Relations and Operations
- **Belong**: \(x \in A\)
- **Union**: \(A \cup B = \{x : x\in A \text{ or } x\in B\}\)
- **Intersection**: \(A \cap B = \{x : x\in A \text{ and } x\in B\}\)
- **Complement**: \(A^c\) (or \(\overline{A}\), \(A'\)) — objects under consideration not in \(A\)
- **Difference**: \(A\\setminus B = A\cap B^c\)
- **Subset / Superset**: \(B \subset A\) iff every element of \(B\) is in \(A\)
- **Null set**: \(\emptyset\)
